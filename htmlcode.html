HTML Boilerplate Skeleton

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My Page</title>
</head>
<body>

</body>
</html>

Breakdown & Notes

  • <!DOCTYPE html> tells the browser that this is an HTML5 document.
  • <html lang="en"> is the root element that wraps everything and sets the primary language to English.
  • <head> acts as a container for metadata, links, and the page title (hidden from the actual visible page).
  • <meta charset="UTF-8"> sets the character encoding so text and symbols render correctly.
  • <meta name="viewport" content="width=device-width, initial-scale=1.0"> ensures your layout scales properly and looks good on mobile screens, but you may need to adjust it for specific designs.
  • <title> sets the text shown in the browser tab.
  • <body> contains all the actual visible content of your webpage.
  • Remember to close all your tags properly to avoid rendering issues.

Adding more detail to your head tag

<head>
    <link rel="icon" href="images/head.ico" type="image/x-icon">
    <link rel="preconnect" href="https://fonts.googleapis.com">
    <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
    <link href="https://fonts.googleapis.com/css2?family=Sniglet&display=swap" rel="stylesheet">
    <link rel="stylesheet" href="styles.css">
</head>

Breakdown & Notes

The Core Element: <link>

Defines a relationship between the current document and an external resource. It is always placed inside the <head> section.

  • rel (Relationship): Specifies how the current page relates to the linked resource (e.g., stylesheet, icon, preconnect).
  • href (Hypertext Reference): Specifies the URL or file path of the external resource.
  • type: Specifies the media type or MIME type of the linked document (e.g., image/x-icon).
  • crossorigin: Instructs the browser to fetch the resource with CORS enabled, improving performance when loading external fonts.
  • <link rel="icon" ...> sets the small icon that appears in the browser tab.
  • <link rel="preconnect" ...> tells the browser to set up an early connection to Google Fonts before files are requested, speeding up page load times.
  • <link rel="stylesheet" ...> links your main custom CSS file to style the webpage.

Breakdown & Notes

The Core Element: <body>

Contains all the visible content of an HTML document, such as headings, paragraphs, images, hyperlinks, and tables.

  • <h1>: Defines the most important heading on the page.
  • <img>: Embeds an image into the page (an empty element with no closing tag).
  • <p>: Defines a standard text paragraph.
  • <address>: Indicates that the enclosed HTML provides contact information for a person or organization.
  • title: Adds a tooltip text description that appears when a user hovers over the element.
  • src: Specifies the file path or URL for an image.
  • alt: Provides alternative text for an image if it fails to load or for screen readers.
  • target: Specifies where to open a linked document (e.g., _blank opens it in a new tab).
  • <img ... style="display: block; margin-left: auto; margin-right: auto;"> centers the image horizontally on the page using inline CSS.
  • <a href="mailto:..."> creates an active email link that automatically opens the user's default email client when clicked.
  • <div>: A generic, block-level container used to group visible elements together (like buttons) for easier layout and styling without adding any visual effect of its own.
  • class: An attribute used to assign a name to an element, acting as a hook for CSS stylesheets to target and style groups of items consistently.
  • title: An attribute that provides extra information, displayed by the browser as an interactive tooltip when the user hovers over the element in the body. You can see title of the text when you hover over it.
  • style: An attribute used to apply CSS rules directly (inline) to a specific element on the page, such as adding borders or adjusting margins on the fly.

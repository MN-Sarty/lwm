The Basic Body of HTML code

This is the basic structure of an HTML page. It includes the doctype declaration, html, head, and body tags. The head section contains meta information, title, and links to stylesheets and scripts. The body section contains the content of the page.


<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Page Title</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>

    <!-- Page content goes here -->

    <script src="script.js"></script>
</body>
</html>

Notes:

  • <!DOCTYPE html>: Tells the browser that the document is written in modern HTML5.
  • <html lang="en">: The root container wrapping everything, specifying that the page is in English.
  • <head>: Houses behind-the-scenes metadata, character encoding (UTF-8), responsive scaling, tab titles, and CSS stylesheet links.
  • <body>: Contains all the visible layout elements, text, and structure users interact with.
  • <script src="script.js"></script>: Placed at the bottom to ensure interactive scripts load smoothly after the HTML renders.

My <head> Section

This is the head section of my index.html file. It contains meta information, title, and links to stylesheets and scripts.


<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Landing Page</title>
    <link rel="icon" href="images/head.ico" type="image/x-icon">
    <link rel="preconnect" href="https://fonts.googleapis.com">
    <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
    <link href="https://fonts.googleapis.com/css2?family=Sniglet&display=swap" rel="stylesheet">
    <link rel="stylesheet" href="styles.css">
</head>

Notes:

  • <meta charset="UTF-8">: Ensures the page correctly displays special characters and symbols.
  • <meta name="viewport" content="width=device-width, initial-scale=1.0">: Makes the page responsive on different devices.
  • <title>: Sets the title of the page that appears in the browser tab.
  • <link rel="icon" href="images/head.ico" type="image/x-icon">: Links to the favicon that appears in the browser tab.
  • <link rel="preconnect" href="https://fonts.googleapis.com">: Preconnects to Google Fonts for faster loading.
  • <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>: Preconnects to Google Fonts' static content with cross-origin support.
  • <link href="https://fonts.googleapis.com/css2?family=Sniglet&display=swap" rel="stylesheet">: Links to a specific Google Font for use in the page.
  • <link rel="stylesheet" href="styles.css">: Links to the external CSS stylesheet for styling the page.

Basic Structure of a CSS File

The basic structure of a CSS file includes selectors and declarations. Selectors target HTML elements, and declarations define the styles to be applied to those elements. You can have this as a file separate from your html file, or use the <style> tag within the <head> section.


selector {
    property: value;
}
.class {
    property: value;
}

Notes:

  • selector: Targets specific HTML elements to apply styles.
  • property: The CSS property you want to change (e.g., color, font-size).
  • value: The value assigned to the property (e.g., red, 16px).
  • .class: Targets elements with a specific class attribute, under the class="class-name" tag in your html file.

Basic Structure of a JavaScript File

The basic structure of a JavaScript file includes functions and event listeners. Functions define reusable blocks of code, and event listeners respond to user interactions. You can have this as a file separate from your html file, or use the <script> tag within the <body> section.


function myFunction() {
    // Code to be executed
}

Notes:

  • function: Defines a reusable block of code that can be called by its name.
  • myFunction(): The name of the function, which can be called to execute the code inside it.
  • // Code to be executed: A comment indicating where the code to be executed should be placed.

My <script> Section

This is the script section of all my html files. It contains all the JavaScript code that adds interactivity and dynamic behavior to the website. A main one being the sidebar menu.


function toggleMenu() {
                const sidebar = document.getElementById('sidebar');
                const button = document.querySelector('.menu-button');
                const pageContent = document.getElementById('pageContent');

                sidebar.classList.toggle('open');
                button.classList.toggle('open');
                pageContent.classList.toggle('shifted');
            }

Notes:

  • toggleMenu(): The name of the function, which can be called to toggle the sidebar menu.
  • sidebar: The element representing the sidebar.
  • button: The element representing the menu button.
  • pageContent: The element representing the main page content.
  • classList.toggle(): A method that adds or removes a class from an element's class list, allowing for dynamic styling changes.
  • 'open': A class that is toggled on the sidebar and button elements to show or hide the sidebar menu.
  • 'shifted': A class that is toggled on the page content to shift it when the sidebar is open.
  • document.getElementById(): A method that retrieves an element by its ID.

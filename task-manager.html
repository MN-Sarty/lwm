A few notes on Taskie

Index.html File

This is the index.html file for my task manager project. It is the page you see before logging in or signing up.

My <head> Section

This is the <head> section of my index.html file. It contains the meta tags, title, and links to the CSS and Google Fonts.


<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Taskie</title>
    <link rel="stylesheet" href="style.css">
    <link rel="icon" href="images/Taskie.png" type="image/png">
    <link rel="preconnect" href="https://fonts.googleapis.com">
    <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
    <link href="https://fonts.googleapis.com/css2?family=Lora:ital,wght@0,400..700;1,400..700&display=swap" rel="stylesheet">
</head>

Notes:

  • I used the Lora font for the headings and body text.
  • I used a favicon created by a friend for the tab icon.
  • My page title changed from my previous website because this is a different project.
  • The code that you use to import fonts is usually on the Google fonts website.

My <body> Section

This is the <body> section of my index.html file. It contains the main content of the page, including the header, main content, and footer.


<body>
    <h1>Taskie - Welcome</h1>
    <p>Welcome to Taskie, the app that will hopefully help you get your life together and actually get things done. ☺</p>
        
    <main class="app-card">
            
        <selection id="choice-view" class="view-section">
            <div class="choice-buttons">
                <a href="signup.html" class="btn-primary-link">I'm new here...</a>
                <a href="login.html" class="btn-secondary-link">I already have an account</a>
            </div>
        </selection>
    </main>

</body>

Notes:

  • <h1> is used for the main heading.
  • <main> is used to define the main content area.
  • <selection> is used to create a selection element for the initial choice view. This means it allows the user to select from a list of options.
  • <div> is used to create a container for the choice buttons.
  • <a> is used to create links to the signup and login pages.
  • <class> is used to define the CSS classes for styling.
  • In this file, we didn't add a link to a JavaScript file, because the functionality is currently handled by the HTML and CSS alone.

Signup.html File

This is the signup.html file for my task manager project. It is the page you see when you click on the "I'm new here..." button on the index.html page.

My <head> Section

Although my <head> section remains the same across all pages, it's important to ensure that each page has the correct meta tags and title.


<head>
    <title>Taskie - Sign Up</title>
</head>

Notes:

  • The title of the page is changed to "Taskie - Sign Up" to reflect the purpose of this page.
  • All other meta tags and links remain the same as in the index.html file.

My <body> Section

This is the <body> section of my signup.html file. It contains the main content of the page, including the header, main content, and footer.


<body>
    <h1 style="font-size: 30px;">Taskie - Sign Up</h1>
    <p style="font-size:18px;">Create a new account to start managing your tasks effectively.</p>

    <main class="app-card">
    
        <a href="index.html" class="back-btn-link" style="padding-top: 0.5px;">← Back</a>
        <h2>New User Registration</h2>
        <form id="signup-form">
        <div class="input-group">
            <label for="signup-name">What can we call you?</label>
                <input type="text" id="signup-name" required placeholder="Type your name here...">
        </div>
        <div class="input-group">
            <label for="signup-username">Username:</label>
            <input type="text" id="signup-username" name="username" required placeholder="Type your username here...">
        </div>
        <div class="input-group">
            <label for="signup-email">Email:</label>
            <input type="email" id="signup-email" name="email" required placeholder="Type your email here...">
        </div>
        <div class="input-group">
            <label for="signup-password">Password:</label>
                <input type="password" id="signup-password" name="password" required placeholder="Type your password here...">
        </div>
        
        <div class="terms-group" style="align-items: center;">
            <input type="checkbox" id="terms-checkbox" disabled style="align-items: center;">
            <label for="terms-checkbox" style="align-items: center;">I agree to the <a href="terms.html" id="open-terms-link">Terms and Conditions</a>
        </div>
        
        <div id="podcast-question-group" class="input-group hidden">
            <label for="podcast-answer">What's my favorite podcast?</label>
            <input type="text" id="podcast-answer" placeholder="Type the answer here..." required>
        </div>
        <a href="dash.html">
            <button type="submit" id="signup-submit-btn" class="btn-primary-link" disabled>Sign Up</button>
        </a>
    </form>
    </section>
    </main>

    <script type="module" src="signup.js"></script>
</body>

Notes:

  • <h2> is used for the main heading, but is often smaller than <h1>.
  • <form> is used to create an HTML form for user input.
  • <id> attributes are used to uniquely identify HTML elements.
  • <label> elements are used to define labels for form controls.
  • <input> elements are used to create interactive controls for web-based forms.
  • <input type="">defines the kind of input data type.
  • <required placeholder=""> attributes ensure that the field is filled out and provide a hint to the user.
  • <section> is used to group related content, although you can also use other semantic elements like <div>.
  • In this file, there is a JavaScript file linked to handle form validation and submission.

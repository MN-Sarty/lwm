Media tags

@media (max-width: 600px) {
    body {
        font-size: 14px;
    }
}

Breakdown & Notes

  • @media: An at-rule in CSS used to create responsive designs by applying a block of styles only when specific conditions—such as screen width or device orientation—are met. You don't typically need to add a media tag to your code if your web app will just be viewed on the device you built it on.
  • (max-width: 600px): The media feature condition that triggers the CSS styles inside the brackets only when the browser window or viewport width is 600 pixels or narrower.
  • max-width: 480px: Small mobile screens (portrait orientation).
  • max-width: 768px: Tablets and larger mobile screens.
  • max-width: 1024px: Laptops, small desktop displays, and tablets in landscape.
  • min-width: 1200px: Large desktop monitors.

CSS tags

How HTML Connects to CSS: HTML provides the structure (you write tags like <h1>, <p>, or <hr> to put content on the page). CSS provides the style. By writing the exact same name in your CSS file (like h1 { ... }), you create a direct target match—telling the browser to find every single <h1> element on the page and apply those rules to it!

h1 {
    font-size: 30px;
    padding-left: 10px;
    font-family: 'Sniglet';
}
p {
    font-size: 16px;
    padding-left: 20px;
    padding-right: 20px;
}
hr {
    margin: 20px 20px;
}

Breakdown & Notes

  • <h1>: Defines the highest-level and most important heading on a page, typically used for main titles.
  • <p>: Defines a standard block of text as a paragraph, adding automatic margins above and below it.
  • <hr>: Represents a thematic break or horizontal separator line between sections of content (an empty element with no closing tag).
  • font-size: Sets the size of the text (e.g., 30px or 16px).
  • font-family: Specifies the typeface to be used for the text (e.g., 'Sniglet').
  • padding-left / padding-right: Sets the inner spacing inside an element on its left or right side, pushing the content inward from the border.
  • margin: Sets the outer spacing around an element; when two values are given (e.g., 20px 20px), the first value applies to the top/bottom and the second applies to the left/right.

CSS comments

CSS comments are used to add notes or explanations within the code. They are ignored by the browser and do not affect the styling of the webpage. Comments are enclosed within /* and */.

/* This is a comment in CSS */

Breakdown & Notes

  • /* ... */: CSS comments are enclosed within /* and */. They are used to add notes or explanations in the code, which are ignored by the browser during rendering.

CSS Tags

How Class Tags Work: Unlike tag selectors (which target every single element like all <p> tags), a class selector uses a dot prefix (like .sidebar) to target specific, custom-labeled elements in your HTML (e.g., class="sidebar"). This allows you to style individual elements differently even if they share the same HTML tag.

/* Sidebar and layout shift rules */
.sidebar {
    width: 200px;
    padding: 90px 20px 20px;
}
.page-content p {
    padding: 20px;
    padding-top: 10px;
}
.page-content h1 {
    padding-left: 20px;
    padding-top: 20px;
}
.page-content.shifted {
    transform: none; /* No shift for small screens */
}

Breakdown & Notes

  • width: Sets the horizontal width of an element (e.g., 200px for the fixed sidebar).
  • transform: none: Disables any active visual transforms or movement, resetting the element back to its default position.
  • .page-content p: A descendant selector that targets only paragraphs (`<p>`) that are located *inside* an element with the class `page-content`.
  • .page-content.shifted: Targets an element that has *both* classes applied simultaneously (no space between them).
.menu-button {
    top: 10px;
    left: 0px;
    width: 35px;
    height: 35px;
}

Breakdown & Notes

  • top / left: Position offsets that control how far an element is pushed down from the top or away from the left. Note: These properties only take effect when the element's position is set to absolute, relative, or fixed.
  • width / height: Sets the explicit horizontal and vertical dimensions of the element (making it a compact 35x35 pixel interactive square, perfect for an icon button).
.sidebar {
    position: fixed;
    top: 0;
    left: 0; /* Hide the sidebar initially */
    width: 250px;
    height: 100%;
    background-color: #342519;
    color: #ede6d9;
    padding: 90px 30px 30px;
    display: flex;
    flex-direction: column;
    z-index: 1000; /* Ensure the sidebar is above other elements */
    transform: translateX(-100%); /* Hide the sidebar initially */
    transition: transform 0.35s ease; /* Smooth transition for sliding effect */
}
.sidebar.open {
    transform: translateX(0); /* Slide the sidebar into view */
}
.sidebar nav {
    display: flex;
    flex-direction: column;
    gap: 20px;
}
.sidebar nav a {
    color: #ede6d9;
    text-decoration: none;
    font-size: 18px;
    transition: color 0.2s ease;
}
.sidebar-button {
    position: fixed;
    top: 20px;
    left: 20px;
    width: 45px;
    height: 45px;
    display: flex;
    flex-direction: column;
    justify-content: center;
    align-items: center;
    gap: 5px;
    background: none;
    border: 2px solid #ede6d9;
    cursor: pointer;
    z-index: 1001; /* Ensure the button is above other elements */
}
.sidebar nav a:hover {
    transform: translateX(5px);
}
.menu-button.open span:nth-child(1) {
    transform: translateY(8px) rotate(45deg);
}

Breakdown & Notes

  • position: fixed: Pulls an element out of the normal page flow and locks it to a specific spot relative to the browser window, so it stays in place when scrolling.
  • z-index: Controls the stacking order of overlapping elements. A higher number (like 1000 or 1001) ensures elements like navigation bars and buttons sit visibly *on top* of standard page content rather than sliding underneath it.
  • transform: translateX(): Moves an element horizontally across the screen without affecting surrounding layout flows. Using -100% pushes the sidebar completely off-screen to the left, while 0 returns it to its natural position.
  • transition: Specifies how long a property change should take when animating (e.g., 0.35s ease creates a smooth sliding effect instead of an instant snap).
  • display: flex with flex-direction: column: Turns an element into a flexible container that stacks its children vertically in a column layout.
  • gap: Sets the exact spacing distance between flexbox or grid items without needing individual margins on every child element.
  • :hover: A pseudo-class that applies styles only when the user's mouse cursor is resting over the element (such as shifting a link slightly to the right).
  • :nth-child(): A structural pseudo-class that targets a specific child element based on its numerical order inside its parent container.
.menu-button.open span:nth-child(2) {
    opacity: 0;
}
.menu-button.open span:nth-child(3) {
    transform: translateY(-8px) rotate(-45deg);
}
.page-content {
    transition: transform 0.35s ease;
    width: 90%;
    max-width: 1000px;
    margin: 0 auto;
}
.page-content.shifted {
    transform: translateX(250px); /* Shift the content to the right when the sidebar is open */
}

Breakdown & Notes

  • opacity: Controls the transparency of an element. Setting it to 0 makes the element completely invisible (used here to fade out the middle line of the hamburger menu icon when it transforms into an "X").
  • max-width: Sets an upper limit on how wide an element can expand, ensuring your content lines don't stretch too wide on large desktop monitors.
  • margin: 0 auto: A classic centering technique where top/bottom margins are set to 0 and left/right margins are set to auto, automatically centering a block container horizontally on the page.
  • transform: translateX(250px): Moves an element 250 pixels to the right along the horizontal X-axis. This matches your sidebar's width so the main page content slides over neatly when the sidebar opens.

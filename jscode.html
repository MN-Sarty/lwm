How to link your js to your html file

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Learn with me</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>

    <!-- Your page content goes here -->

    <!-- Link your JavaScript file at the bottom of the body -->
    <script src="script.js"></script>
</body>
</html>

How to write simple js for a sidebar

function toggleMenu() {
    const sidebar = document.getElementById('sidebar');
    const button = document.querySelector('.menu-button');
    const pageContent = document.getElementById('pageContent');

    sidebar.classList.toggle('open');
    button.classList.toggle('open');
    pageContent.classList.toggle('shifted');
}

Breakdown & Notes

  • Visual Appearance & Behavior: When a user clicks the hamburger button, this function acts as a switch: it slides the dark burgundy sidebar into view, morphs the 3-line icon into an "X" animation, and smoothly shoves the main page content over to the right so nothing gets covered up. Clicking it again reverses everything!
  • Core Concepts:
    • function toggleMenu() { ... }: Defines a reusable block of JavaScript instructions that runs whenever it is called (such as via an HTML onclick attribute).
    • const: Declares a constant variable whose value won't be reassigned.
    • document.getElementById(): Finds and grabs a specific HTML element using its unique id.
    • document.querySelector(): Finds and grabs the first HTML element that matches a CSS selector (like a class).
    • .classList.toggle('className'): A built-in JavaScript method that checks if an element already has a class; if it does, it removes it, and if it doesn't, it adds it. This is the secret to smooth state switches!
